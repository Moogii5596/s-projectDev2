> **⚠ [[01_plan_draft]]-ээс өөрчлөх санал (батлуулах — §6 Ш-1):** анхны цувааны v0.2.1 = ADR-003 **ба** C-01/C-04/C-12 (3 д.х.). Энд хоёр хуваав:
> (а) хоолны тооцоо өөрчлөгдөх (C-01, C-04) ба нэвтрэлт/эрх өөрчлөгдөх (ADR-003) нь **хоёулаа өндөр эрсдэлтэй** — нэг хувилбарт байвал staging дээр зөрүү гарахад шалтгааныг ялгахад хэцүү;
> (б) C-09 (ажилтны профайл) нь ажилтан ↔ хэрэглэгч холбоос дээр тулгуурладаг тул ADR-003-тай нэг хувилбарт;
> (в) V2-01 (гэрээ/үнэ) нь V2-03/V2-04-ийн суурь — эрт эхлэх нь v0.2.4-ийн ачааллыг бууруулна.

**Хувилбар бүрийн урсгал (v0.2.0-ийн сургамж — PROC-013/014, CI-005~007, PS-003):**
1. Техникийн төлөвлөгөө → **"Батлав"** → код (cloud тест бүгд ногоон, шинэ тест хуучин кодон дээр унахыг шалгасан — SEC-004)
2. Таны машин: `install → db:generate → supabase:reset → dev:test-user → camp_e2e_grant → test → integration → e2e` (CI-ийн дараалал — зааврыг `ci.yml`-ээс хуулна)
3. Commit → **CI ногоон** → tag
4. Staging дадлага (`pilot.ps1 -Profile staging … upgrade`) → `camp:snapshot` A ↔ B — **хоолны тооцоо өөрчлөгдөх хувилбарт (v0.2.1, v0.2.3–4) "хүлээгдэх зөрүү"-гийн жагсаалт** урьдчилж бичигдсэн байна (§5)
5. Пилот: `pilot.ps1 upgrade -Tag v0.2.x` (v0.2.0-оос нэг команд) → утаснаас шалгах → хэрэглэгчдэд мэдэгдэл → FB төлөв

## 2. v0.2.1 — Хоолны тооцооны загвар (албан тушаал, хоолгүй хэлтэс)

### Бизнесийн асуулт — ✅ хариулсан (2026-10-11 21:40), дэлгэрэнгүй [[04_v0.2.1_tech_plan]] §1
- **Q1:** Хэлтсээс хоолны байршлыг бүр мөсөн хасна → **албан тушаал (анхдагч) → ажилтан (эцсийн)**, эрхтэй адил загвар
- **Q2:** Албан тушаал = байгууллагын нийтийн каталог (кемп бүрт анхдагч утга)
- **Q3:** Хоолгүй = хоолны тоонд огт орохгүй, ирц/хоног/өрөөнд хамаарна; зардал хэн даах → V2-04
- **Q4:** Байрны төрлийг админ үүсгэнэ (каталог)
- **Q5:** Тухайн өдрийн тооцоолсон ээлжээр шүүнэ (Claude-д даатгав)

### Ажил
- [ ] **C-01** Албан тушаалын каталог (код, нэр, хоолны байршил?, ээлжийн загвар?, идэвхтэй) + ажилтанд холбох; импорт/экспортод `position` → каталог (одоо чөлөөт текст → шилжүүлэх migration: текстээс каталог үүсгэнэ)
- [ ] **C-01** `presence.ts`: хоолны байршил/ээлжийг албан тушаал → хэлтэс дарааллаар; golden тестэд шинэ кейс (одоогийн кейсүүд **өөрчлөгдөхгүй**)
- [ ] **C-04** Хэлтэст `meals: none` тохиргоо → `presence` алгасна; хоолны задаргаанд "хоолгүй" хэсэг (тоонд орохгүй, харагдана)
- [ ] **C-12** Байрны төрөл; байранд хөрөнгө байрлуулах; өрөөний самбараас засварын хүсэлт/хөрөнгө харах
- [ ] **C-14** Ирцийн жагсаалтад ээлжээр шүүх
