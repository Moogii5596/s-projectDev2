# v0.2 бүрэн гүйцэт систем — нэгдсэн төлөвлөгөө (v0.2.4 … v0.2.10)

> **Зорилго (хэрэглэгч, 2026-10-19):** v0.2 = **бүрэн гүйцэт систем** → байгууллага дээр **пилотыг бүрэн нэвтрүүлнэ** → v0.3 = бодит feedback.
> Шаардлага: тохиргоо системийн түвшинд · HR бүрэн мэргэжлийн модуль · орчуулга/нэр томьёог админ шийднэ · нэвтрэхэд эхлээд Feed · Кемп модуль бүрэн.
> **2026-11-07 бүрэн шинэчилсэн** (хэрэглэгч): (1) ажил хойшлуулахгүй, «хөнгөн» хувилбаргүй — бүгд production-д бэлэн; (2) **цөм = модуль ажиллуулах хөдөлгүүр, модуль = зөвхөн бизнесийн логик** → [[ADR-009_Module_Engine]]; (3) нийтлэг боломжийг нэг удаа цөмд; (4) үндсэн баримттай нийцвэл батлуулахгүй шууд хийнэ (`AGENTS.md`).
> Энэ файл = v0.2.4–v0.2.10-ийн **ганц төлөвлөгөө** (хүрээ, дараалал, хамаарал, хугацаа). Идэвхтэй хувилбарын нарийвчилсан checklist → тухайн `NN_v0.2.x_tech_plan` (одоо [[10_v0.2.4_tech_plan]]); дараагийн хувилбарын tech plan-ийг өмнөх release-ийн дараа энэ файлаас үүсгэнэ. ID, төлөв → [[00_backlog_and_tech_debt]].

## 2. Зарчим (бүх хувилбарт)

1. **Нийтлэг нь цөмд:** хувилбар бүр өөрт хэрэгтэй цөмийн боломжийг нэмнэ (ADR-009 §2.3); модульд нийтлэг кодын түр шийдэл ✖. Хувилбарын дотор **дараалал заавал биш** — цөм ба модулийн ажил, уялдаатай блокууд зэрэг явна; уялдаатай бол гэрээг (interface, DTO, DB schema) эхэлж repo-д бичнэ (`AGENTS.md` §1-4).
2. **Модуль = manifest + бизнесийн логик** (ADR-009 §2.2). Цөм → модуль, модуль ↔ модуль import ✖ (CI).
3. **Тохиргоо > код** (v0.2.3 G-1, G-8): урсгал, нэгж, дүрэм, тайлан — өгөгдөл; нэг байгууллагын жишээ = тестийн fixture.
4. **Эрхээр** (ADR-007), **3 хэл + нэр томьёо** (`term.*`), **утас эхэнд** (390px), эрхгүй үйлдлийг нуух, бөөн өөрчлөлт = preview → батлах ([[PRD-04_UI_UX_Architecture_Spec]] §2).
5. **PII:** маск, хандалтын лог, зөвхөн эрхтэй; экспорт эрхтэй; HR баримт шифрлэгдсэн (M-7).
6. **A = B:** өгөгдлийн загварын өөрчлөлт бүрт эрх, хоолны тоо, үлдэгдлийн snapshot (staging, бодит өгөгдөл).
7. **Блок бүр бүрэн** (`AGENTS.md` §2): DB → API → UI → 3 хэл → тест; endpoint бүр UI-д. Release бүр: staging → pilot.
