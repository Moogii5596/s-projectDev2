# v0.2 бүрэн гүйцэт систем — нэгдсэн төлөвлөгөө (v0.2.4 … v0.2.9) — ✅ батлагдсан 2026-10-19

**Архитектурын гол дүгнэлт:**
1. HR-ийг «мэргэжлийн» болгох нь **өгөгдлийн загварын өөрчлөлт** (ажилтан ↔ кемп салгах) — Кемпийн хоолны тоо (presence) үүнээс шууд хамаардаг → **хоолны тоо A = B snapshot заавал**, HR-ийг Кемпийг дуусгахаас **өмнө** хийнэ (Кемпийн шинэ функцууд эцсийн HR загвар дээр бичигдэнэ).
2. Батлах урсгал, мэдэгдэл, файл, амралтын өдрийн календарь, нэр томьёо — HR ба Кемп **хоёуланд** хэрэгтэй **суурь** → эхэнд (v0.2.4).
3. Орчуулгын override аль хэдийн байгаа — v2 нь дээр нь **засварлагч + нэр томьёо** нэмнэ (дахин бичихгүй).
4. «Тохиргоо, урсгал, нэгжийг кодонд хатуу бичихгүй» (v0.2.3 G-1, G-8) — бүх хувилбарт хүчинтэй.
