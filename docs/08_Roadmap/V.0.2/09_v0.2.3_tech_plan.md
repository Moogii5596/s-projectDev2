### 1.1 Гэрээний загвар (Q12 хариулт, 2026-10-19 01:12–01:25)

**Жишээ гэрээ (пилотын катеринг, нэр/дугаар хадгалахгүй):** нэгж үнэ = 1 хүн/өдөр, НӨАТ багтсан, гэрээний валют CNY → төлбөр MNT (сар бүрийн ханш, гадны эх сурвалжаас); сар бүр: гүйцэтгэгч өмнөх сарын ажлаа 5-ны дотор илгээх → захиалагч батлах, торгууль ба захиалагчийн төлсөн зардлыг хасах → НӨАТ-ын баримтаас хойш 10 ажлын өдөрт 95%, 5% барьцаа 3 сарын дараа (хүүгүй); Монгол/Хятадын амралтын өдөр хугацааг хойшлуулна. Хугацаа 1 жил, ижил нөхцөлөөр сунгагдсан. Торгууль: 7 хоног тутмын сэтгэл ханамж (босго ≥70 хэвийн / 60–70 хөнгөн сануулга / <60 хатуу сануулга + босгоос доош 1% тутамд тогтмол дүн, бутархайг 1% гэж), давтагдах зөрчил (1–2 дахь удаа сануулга, 3 дахиас дүн), ажилтан тутмын торгууль, дараалсан сарын сануулга → дүн / гэрээ цуцлах.
