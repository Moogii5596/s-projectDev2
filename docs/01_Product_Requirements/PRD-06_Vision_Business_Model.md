# PRD-06 — Алсын хараа, хамрах хүрээ ба бизнес загвар

> 2026-10-13 · Төлөв: **Шийдвэр (чиглэл батлагдсан)** — нарийвчилсан PRD/ADR дараа · Холбоотой: [[PRD-01_Core_Vision]], [[PRD-05_Internal_Social_Feed]], [[ADR-004_Feed_Architecture]], [[ADR-006_HR_Core_Module]], [[ADR-005_Org_Connectivity_Domains]]
> Энэ баримт [[PRD-05_Internal_Social_Feed]] / [[ADR-004_Feed_Architecture]]-ийн «сурталчилгаа, худалдааг хассан» (2026-10-11) шийдвэрийг **нийтийн сүлжээний хувьд** сольж байна. Дотоод Feed (v0.3) сурталчилгаа, худалдаагүй хэвээр.

## 1. Эрхэм зорилго
- Ажилчид ERP-ийг **хүчээр** хэрэглэдэг байдлыг халах — хүмүүсийн харилцаа, санаа, асуудлыг бодит ажил, шийдэлтэй холбосон орчинд дуртайяа оролцдог болгох.
- Байгууллагууд мэдээллээ **хэт нууцалдаг** байдлын эсрэг зогсох — ил байж болох мэдээллийг нээлттэй болгох.
- Нийгэмд том өөрчлөлт авчрах, урт хугацааны амбицтай төсөл.

## 2. Алсын хараа: хүмүүсийн яриаг ажил, үр дүнтэй холбосон сүлжээ (✅ 2026-11-07)
> Түүх: 2026-10-11 — «гаднаа нийгмийн сүлжээ, цаанаа ERP» (хэрэглэгч сошиал апп мэт, цаана нь ERP). 2026-11-07-нд хэрэглэгч үүнийг **яриа → хамтын шийдвэр → ажил → үр дүн** чиглэлээр өргөтгөж баталсан.
- S Project нь энгийн пост, лайк төвтэй сүлжээ биш; **яриа → хамтын шийдвэр → ажил → үр дүн** урсгалыг дэмжих хамтын ажиллагааны орчин байна. Сошиал мэт ойлгомжтой интерфэйс нь оролцоог хялбарчилж, ERP нь зөвшөөрөгдсөн ажлын урсгалыг гүйцэтгэнэ.
- Пост бүрийг ажил болгохгүй. Хэрэглэгчид шаардлагатай үедээ л хэлэлцүүлгээс санал, асуудал эсвэл ажлын урсгал үүсгэнэ — **чиглэл батлагдсан**; тодорхой шаардлага, UX-ийг пилотоор баталгаажуулна.
- Хувийн сошиал аккаунтаа **ажилтны бүртгэлтэй холбосноор** байгууллагын ил мэдээлэл болон зөвшөөрөгдсөн үйлдлүүдэд (хүсэлт, батлалт г.м.) хандана — «сошиал дотор ERP».
- **Байгууллагын өгөгдөл сошиалаас хатуу тусгаарлагдсан** ([[ADR-001_Tenant_Isolation]], RLS).
- Энэ байршуулалтын шинэчлэл нь v0.2.3 Блок 5-д хэрэгжсэн Feed v0 болон дараагийн батлагдсан блокийн дарааллыг өөрчлөхгүй; шинэ боломж, хувилбарын амлалт болохгүй.

## 3. Хамрах хүрээ — бүх салбар
Систем уул уурхай / кемпээр хязгаарлагдахгүй: хүргэлт, такси, үйлдвэрлэл, дэлгүүр / худалдаа, ресторан, цаг захиалга, зочид буудал, амралтын газар г.м. Кемп модуль нь эхний (пилот) салбар. Үүний дагуу ажилтан системийн суурь HR модульд шилжинэ ([[ADR-006_HR_Core_Module]]).

## 4. Нийгмийн сүлжээний 2 төрөл
| | Байгууллагын дотоод | Нийтийн |
|---|---|---|
| Хэн харна | Тухайн байгууллагын ажилтан | Сүлжээний бүх хэрэглэгч |
| Агуулга | Мэдээ, ХАБ / катерингийн мэдэгдэл, хоолны цэс, ажлын пост ([[PRD-05_Internal_Social_Feed]]) | Хувийн пост, байгууллагын нийтийн хуудас, зар, худалдаа |
| Сурталчилгаа / худалдаа | **Байхгүй** | §5–§6-ийн дагуу |
| Хувилбар | v0.3 ([[00_plan_draft]]) | Тодорхойгүй (v0.3-ын дараа) |

- Ажилтанд хоёулаа **нэг feed-д нийлж** харагдана; цаанаа **хатуу тусгаарлагдсан** (дотоод пост нийтийн хэсэгт хэзээ ч гарахгүй).

## 5. Бизнес загвар
- **Төлбөргүй байгууллага:** сурталчилгаа өргөн харагдана.
- **Төлбөртэй байгууллага:** хүчээр сурталчилгаа санал болгохгүй — зөвхөн шаардлагатай зар.
- **Өөрийн серверт суулгалт:** суурь суулгалтын төлбөр; нийгмийн сүлжээнд **холбогдохгүй** бол өндөр төлбөр; холбогдвол төлбөртэй / төлбөргүй сонголт.
- Хөрөнгө оруулалт одоогоор төлөвлөөгүй.

## 6. Худалдаа (санаа)
- Сүлжээний хэрэглэгч системээр шууд: ресторанаас хоол, зочид буудал / амралтын газрын захиалга, хүргэлт, такси дуудлага (Uber маягийн).
- **Байгууллага хоорондын худалдаа:** жишээ нь ресторанд мах дуусахад гэрээт нийлүүлэгч рүү захиалга автоматаар очих (Inventory / Vendor модуль, [[sprint_9_modules]]-ийн суурь дээр).

## 7. Нүүр хуудас — `gobiverse.website`
- Үндсэн хаягт S Project-ийн танилцуулга: техник, аюулгүй байдал, бизнесийн зорилго.
- Зорилго: байгууллагуудад ийм систем хийгдэж байгааг мэдээлэх + хөрөнгө оруулагчдад танилцуулга. Системийн дэлгэцийг концепц загвараар (бүх салбарыг хамруулж) харуулна ([[08_Roadmap/_design_mockups/README|_design_mockups]]).
- Байршуулалт: GitHub → Vercel → Cloudflare ([[ADR-005_Org_Connectivity_Domains]] §2.4).
