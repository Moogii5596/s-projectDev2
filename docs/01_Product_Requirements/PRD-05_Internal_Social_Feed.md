# PRD-05 — Байгууллагын дотоод нийгмийн сүлжээ (Feed)

> 2026-10-11 · Төлөв: **Хамрах хүрээ батлагдсан** · Хувилбар: v0.3 (Кемп v0.2.x-ийн дараа) · Архитектур: ADR-003 (хэрэглэгч, эрх), ADR-004 (Feed)

## 1. Алсын хараа
Ажилтан системд ороход цэс биш **Feed** угтана: хамт олны мэдээ, анхааруулга, өнөөдрийн хоолны цэс, өөрийн ажлын хүсэлтийн явц. Гаднаа нийгмийн сүлжээ шиг хялбар, цаанаа ERP-ийн ажлын урсгал (засвар, гомдол, тээвэр) ажиллана.

**Шийдвэр (2026-10-11):**
- **Зөвхөн байгууллагын дотор** (гадны хэрэглэгч, байгууллага хоорондын харилцаа алга).
- **Хассан:** сурталчилгаа, төлбөр, худалдаа. **Хойшлуулсан:** чат.
- Ажилтан **хязгаарлалтгүй** пост хийнэ (өглөөний мэндчилгээ, цалингийн тухай, уурхайн тоосжилтын зураг…); зохицуулагч нуух, бичих эрхийг хугацаатай хаах боломжтой.

## 2. Хэрэглэгчид ба жишээ
| Хэн | Жишээ |
|---|---|
| Ажилтан | "Өглөөний мэнд!" · "Уурхайн тоосжилт их байна" + зураг · **"Блок 7-00 ус алдаж байна"** → засварын хүсэлт · **"Өдрийн хоол давс ихтэй"** → хоолны гомдол |
| ХАБ ажилтан | "Өнөөдөр цас орно, болгоомжтой ажиллаарай" — анхааруулга, дээр тогтоох |
| Катеринг менежер | Өнөөдрийн цэс (5 цуйван…) · "Гэдэс идэж чаддаггүй хүн өөр хоол захиалж болно" |
| Засварчин / кемп менежер | Засварын хүсэлтийг Feed-ээс харж, явцыг шинэчилнэ; сэтгэгдлээр харилцана |
| Зохицуулагч | Зүй бус постыг нууж, зохиогчид мэдэгдэнэ; бичих эрхийг хугацаатай хаана |

## 3. Функц (v0.3)
1. Feed: пост (текст, ≤6 зураг), лайк, сэтгэгдэл, хуудаслалт; кемп/байгууллагаар шүүх.
2. Анхааруулга (эрхтэй), дээр тогтоох.
3. Өнөөдрийн хоолны цэс Feed-ийн дээд хэсэгт (катеринг өдөр бүр оруулна).
4. Ажлын пост: засварын хүсэлт, хоолны гомдол → тасалбар автоматаар; **явц постын доор**; харагдах эрх = эрхийн матриц (гүйцэтгэгч/батлагч + зохиогч).
5. Системийн пост: хог тээвэр г.м. ажлын бүртгэл → холбогдох эрхтэй хүмүүст.
6. Мэдэгдэл (апп дотор), утсанд апп шиг суулгах (PWA); push — дараа.
7. Зохицуулалт: мэдэгдэх (report), нуух + мэдэгдэл, бичих эрхийг хугацаатай хаах, түүх.
8. 3 хэл (mn/en/zh) — v0.2.0-ын суурь; хэрэглэгчийн пост орчуулагдахгүй.

## 4. Хамаарал (v0.2.x-д бэлтгэгдэнэ)
- v0.2.0: өөрчлөлтийн түүх (Feed-ийн "явц"-ын эх сурвалж), олон хэл, Excel импорт.
- v0.2.1: ажилтан ↔ хэрэглэгч, утсаар нэвтрэх, урилга, **эрхийн матриц** (ADR-003) — Feed-ийн харагдах эрхийн суурь; "Ажилтан" загвар.
- v0.2.3: хоолны цэс/захиалгын бүтэц.

## 5. Амжилтын хэмжүүр (пилот)
- 7 хоногт нэг ч удаа нэвтэрсэн ажилтны хувь (зорилт ≥ 60%)
- Засварын хүсэлтийн ≥ 50% нь Feed-ээр үүссэн
- Засварын хүсэлт → хаагдах дундаж хугацаа (өмнөхөөс буурах)
- Хоолны гомдлын хариу өгөх хугацаа
- Зохицуулалтын тохиолдол (нуусан пост) — хяналтын үзүүлэлт

## 6. Нээлттэй
- Push мэдэгдэл (Web Push) v0.3-д уу, дараа уу.
- Хостинг (ADR-002): зургийн хэмжээ өсөхөд нэг PC хангалттай эсэх.
- Пост хадгалах хугацаа (жнь 1 жил) ба хуучныг архивлах.
