# PRD-02 — Байршуулалтын түвшин (Tier) ба багц

> Хувилбар 2.0 (2026-10-13, бүрэн шинэчилсэн). Техникийн шийдвэр: [[ADR-001_Tenant_Isolation]] (shared / dedicated), [[ADR-005_Org_Connectivity_Domains]] (холболт) · бизнес загвар: [[PRD-06_Vision_Business_Model]] §5 · анхны хувилбар (quota, gRPC, offline матриц): [[PRD-02_Tenant_Tiers.v1]] — архив.

## 1. Гурван түвшин

| | **Tier 1 — Shared** | **Tier 2 — Dedicated** | **Tier 3 — Air-gapped** |
|---|---|---|---|
| Хэнд | Жижиг, дунд байгууллага | Том байгууллага, өөрийн серверт суулгах (пилот Sino Hydro) | Интернэтгүй талбар, өндөр нууцлал |
| Байрлал | Манай нийтийн сервер, олон tenant | Тэдний сервер / VM / PC эсвэл тусгай deploy | Бүрэн дотоод сүлжээ |
| Тусгаарлалт | Нэг DB + RLS (`tenant_id`) | Тусдаа DB + deploy (`DEPLOYMENT_MODE=dedicated`, RLS хэвээр) | Тусдаа, интернэтгүй |
| Холболт (ADR-005) | Нэг tunnel, олон дэд домэйн | Байгууллага бүр өөрийн Cloudflare Tunnel (`<байгууллага>.gobiverse.website`) | Дотоод DNS + сертификат |
| Төлөв | ✅ код бэлэн (`shared` анхдагч) | ✅ пилотод ажиллаж байна | 🧭 v0.4+ (хэрэгтэй эсэх шийдэгдээгүй) |

- DB-д `tenants.tier` (`tier1`/`tier2`/`tier3`) ба `max_users` багана бий, гэхдээ **одоогоор кодонд хязгаар болгон ашиглагдаагүй** (зөвхөн onboarding-д тэмдэглэгдэнэ).
- Нэг дор tier болон `DEPLOYMENT_MODE` нь хоорондоо тохирох ёстой: Tier 1 ↔ `shared`, Tier 2/3 ↔ `dedicated`.

## 2. Багц ба төлбөр (бизнес загвар — [[PRD-06_Vision_Business_Model]] §5)

| Багц | Сурталчилгаа | Нийгмийн сүлжээ |
|---|---|---|
| Төлбөргүй (Tier 1) | Өргөн харагдана | Холбогдсон |
| Төлбөртэй (Tier 1) | Зөвхөн шаардлагатай зар | Холбогдсон |
| Өөрийн серверт (Tier 2) | Суурь суулгалтын төлбөр; сүлжээнд **холбогдохгүй** бол өндөр төлбөр, холбогдвол төлбөртэй / төлбөргүй сонголт | Сонголттой |

## 3. Хязгаар ба боломж (🧭 — шийдэгдээгүй)
Анхны төлөвлөгөөнд байсан, одоо **хэрэгжээгүй**, шийдвэр шаардах зүйлс:
- Модулийн тоо, хэрэглэгчийн тоог багцаар хязгаарлах (`max_users`-ийг хэрэгжүүлэх эсэх).
- Audit log хадгалах хугацааг багцаар ялгах (одоо `camp_audit_log` хугацаагүй хадгалагдана).
- Tier 3: offline-first, локал гарын үсэг (Ed25519), sync зөрчил шийдэх — [[01_Development_Roadmap]] (v0.4+), анхны дэлгэрэнгүй: [[PRD-02_Tenant_Tiers.v1]] §3.

## 4. Шинэ байгууллага холбох (одоогийн журам)
1. Tier сонгох → Tier 2 бол тэдний орчинд суулгах ([[03_Enterprise_VPC_Deployment]]; Windows нэг машин: [[04_Pilot_Camp_Windows]]).
2. Tenant үүсгэх (`pnpm pilot:onboard` / super admin onboarding) → эхний админ хэрэглэгч.
3. Дэд домэйн + tunnel ([[05_Cloudflare_Tunnel]]).
4. Мастер өгөгдөл (Excel импорт) → ажилтан → хэрэглэгчийн урилга ([[pilot-test-guide]]).
