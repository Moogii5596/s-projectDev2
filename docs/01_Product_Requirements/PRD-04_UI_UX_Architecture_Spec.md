# PRD-04 — UX зарчим ба шаардлага

> Хувилбар 2.0 (2026-10-13, бүрэн шинэчилсэн). Frontend-ийн техникийн бүтэц: [[ARCH-05_UI_UX_Architecture_Spec]], [[04_Frontend_Map]] · дэлгэцийн концепц: [[08_Roadmap/_design_mockups/README|_design_mockups]] · анхны хувилбар (slot/manifest, offline UI): [[PRD-04_UI_UX_Architecture_Spec.v1]] — архив.

## 1. Хэрэглэгчийн орчин
- Ажилчдын ихэнх нь **утсаар**, кемпийн сүлжээгээр орно → бүх дэлгэц **390px** өргөнд бүрэн ажиллана (шинэ хуудас бүрийг утасны хэмжээнд шалгана).
- Олон үндэстний ажилтан: **монгол (анхдагч) · 中文 · English**. Хэл: нэвтрэх хуудас ба баруун дээд буланд; сонголт профайлд хадгалагдана → төхөөрөмж → монгол.
- Имэйлгүй ажилчид олон → утсаар нэвтрэх, урилгын линкийг шууд хуулж өгөх боломж.

## 2. Заавал баримтлах зарчим (✅ одоогийн UI)
| Зарчим | Хэрэгжилт |
|---|---|
| Эрхгүй үйлдлийг **нуух** (алдаа гаргахын оронд) | `useCampPermissions` → товч/цэс; хуудас бүхэлдээ эрхгүй бол `NoAccess` |
| Бөөн өөрчлөлт = **урьдчилан харах → батлах** | Excel / хүснэгтийн импорт, олон хүний ирц, роль-загвар хэрэгжүүлэх, орчуулга — preview → confirm |
| Алдааны мессеж хэрэглэгчийн хэлээр, ойлгомжтой | Backend `code` + `params` → орчуулсан мессеж; `ErrorBox` (дахин оролдох) |
| Нэг хэв маяг | Tailwind (gray/blue) + `ui.tsx` компонентууд; шинэ UI сан нэмэхгүй |
| Том жагсаалт хурдан | Cursor pagination, шүүлт (хэлтэс/ростер/албан тушаал/ээлж); virtual scroll — одоо зөвхөн MR жагсаалтад (`@tanstack/react-virtual`) |
| Контекст санах | Сүүлд орсон кемп (`/camp` → сүүлийн кемп; жагсаалт `/camp?list=1`) |
| Нэр томьёо тогтвортой | [[i18n-review]] (жнь "Баг" → "Ростер") |
| Устгахын оронд идэвхгүй болгох | Мастер өгөгдөл `ACTIVE/INACTIVE`, түүх audit log-д |

## 3. Навигаци (одоо)
- Нүүр: идэвхтэй модулийн нүүр (`VITE_MODULES`; пилот = Кемп).
- Кемп: кемп сонголт → ажиллагаа (ирц, ээлж, хоол/байрлалт, өрөөний самбар, засвар, хөрөнгө) · **Системийн тохиргоо** (`/camp/system/:section` — байгууллага, роль, хэрэглэгчийн эрх, каталог, орчуулга). Route-ын бүрэн жагсаалт: [[09_Frontend_Routes]].

## 4. Зорилт (🧭)
- **Feed-ээр угтах нүүр** — ажилтан цэс биш хамт олны мэдээ, хоолны цэс, өөрийн хүсэлтийн явцаар угтагдана (v0.3, [[PRD-05_Internal_Social_Feed]]); дотоод + нийтийн нэг feed ([[PRD-06_Vision_Business_Model]] §4).
- **Модуль бүрийн UI-г динамикаар залгах** (sidebar / dashboard widget / route slot, manifest) — одоо build-ийн `VITE_MODULES`; хэрэгцээ гарвал ([[ARCH-05_UI_UX_Architecture_Spec]] §3).
- **Offline горим** (Tier 3, PWA + локал кэш, sync зөрчлийн дэлгэц) — v0.4+, анхны санаа: [[PRD-04_UI_UX_Architecture_Spec.v1]].
- Хэрэглэгчийн заавар (дүрээр): `docs/_learning/user-guides/` ([[_learning/README|_learning]]).
