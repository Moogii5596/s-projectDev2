# Орчуулгын хяналт (v0.2.0 — Монгол · English · 中文)

> Төлөв: **mn — эх (баталгаатай), en — НООРОГ, zh (简体) — НООРОГ.** Хяналтын зам (2026-10-11 шийдвэр): пилотын хэрэглэгчид буруу/ойлгомжгүй орчуулгыг **FB**-ээр ([[pilot-feedback]], Төрөл: UX, "Орчуулга: <key эсвэл дэлгэц> — <санал>") өгнө → Системийн тохиргоо → Орчуулга-аар шууд засна, долоо хоног бүр кодын анхдагч руу оруулна. en/zh-г Claude гаргасан; Sino Hydro-гийн хятад хэлтэй ажилтан (zh) ба англи хэлтэй ажилтан (en) хянаж баталгаажуулна. Хянаагүй хугацаанд "ноорог" гэж үзнэ.
> Төлөвлөгөө: [[02_v0.2.0_tech_plan]] §0.7

## 1. Юуг хянах вэ

| Хэсэг | Хаана | Тоо (ойролцоо) |
|---|---|---|
| Дэлгэцийн текст (цэс, товч, хүснэгт, маягт) | `packages/i18n/web.{mn,en,zh}.json` | ~610 |
| Серверийн мессеж (алдаа, импортын мөрийн алдаа, Excel загварын толгой/заавар, өөрчлөлтийн түүх) | `apps/core-kernel/src/common/i18n/messages.ts` | ~300 |

Хамгийн хялбар зам — **кодод хүрэхгүй, build хийхгүй**:
1. OWNER/ADMIN эрхтэй хэрэглэгчээр нэвтэрнэ → **Кемп → Системийн тохиргоо → Орчуулга → "Excel татах"**.
2. Файлд багана: `key · Хэсэг (web/server) · Анхдагч (mn) · mn · en · zh`. Хянагч зөвхөн **en** эсвэл **zh** баганыг засна.
3. `{room}`, `{date}`, `{n}` гэх мэт **хувьсагчийг ӨӨРЧЛӨХГҮЙ, УСТГАХГҮЙ** (байрыг нь сольж болно). Дутуу/илүү хувьсагчтай мөрийг систем хүлээж авахгүй (урьдчилсан харагдацад алдаа).
4. Хоосон нүд = анхдагч (кодын) орчуулга хэвээр.
5. "Оруулах" → урьдчилсан харагдац (хуучин → шинэ) → **Баталгаажуулах** → ≤ 60 секундэд бүх нээлттэй хуудсанд шинэчлэгдэнэ. Түүх ба "анхдагч руу буцаах" тэр хуудсанд.

Ингэж засагдсан орчуулга нь **тухайн байгууллагад** хадгалагдана (DB `i18n_overrides`) — дараагийн хувилбар гарахад алдагдахгүй. Хянасан орчуулгыг кодын анхдагч болгох бол Excel файлыг надад (хувийн мэдээлэлгүй тул) илгээнэ — би `web.*.json` / `messages.ts`-д оруулна.

## 3. Хянах дараалал (санал)

1. Нэвтрэх хуудас, цэс, Кемпийн табууд (`auth.*`, `nav.*`, `common.*`, `camp.section.*`, `camp.layout.*`, `camp.home.*`).
2. Ирц, Хоол, Өрөөний самбар, ээлж (`camp.att.*`, `camp.meals.*`, `camp.presence.*`, `camp.board.*`, `camp.shifts.*`, `camp.enum.*`).
3. Алдааны мессеж (серверийн `camp.err.*`, `camp.row.*`, `row.*`, `import.*`, `rooms.*`).
4. Excel загварын толгой ба "Заавар" хуудас (`col.*`, `xlsx.*`, `table.*`, `enum.*`) ба өөрчлөлтийн түүх (`audit.*`).
5. Бусад (засвар, хөрөнгө, тохиргоо).

## 4. Мэдэгдэж буй хязгаарлалт (v0.2.0)

- **Маягтын шалгалтын мессеж** (DTO / class-validator — жнь "code зөвхөн латин үсэг…") монголоор үлдсэн → v0.2.4. Ердийн хэрэглээнд дэлгэц өөрөө шалгадаг тул ховор.
- **DB-ийн хамгаалалтын trigger** (`CAMP_*_LOCKED` г.м. — зэрэгцээ үйлдлийн нөөц хамгаалалт): код + монгол тайлбар.
- **Ирцийн хуучин xlsx загвар** (Ирц → Импорт): толгой, "Заавар" хуудас mn/en; мөрийн алдаа нь урьдчилсан харагдац хийсэн хүний хэлээр хадгалагдана (дараа нь өөр хэлээр нээхэд тэр хэлээрээ харагдана). Шинэ импортууд (ажилтан, хэлтэс) 3 хэлээр бүрэн.
- **Хэрэглэгчийн оруулсан өгөгдөл** (нэр, тайлбар, байршлын нэр) орчуулагдахгүй.
- Нэвтрэхээс өмнөх хэл = энэ төхөөрөмж дээр сүүлд сонгосон, эсвэл **монгол** (утасны хэлийг ашиглахгүй — пилотын утаснууд англи тохиргоотой). Нэвтэрсний дараа профайлын хэл.
