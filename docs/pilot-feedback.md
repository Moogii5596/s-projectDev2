# Кемп пилот — Санал, асуудлын бүртгэл

> Пилот: Sino Hydro · https://desktop-13n3elv.tail7fe33e.ts.net · Хувилбар: `v0.1.6.1`
> Туршилтын заавар: `docs/pilot-test-guide.md` · v0.2-ын бүртгэл: `docs/08_Roadmap/V.0.2/00_backlog_and_tech_debt.md`

**Бүртгэгч:** систем хариуцагч. Ажилтнууд санал, асуудлаа утсаар, чатаар эсвэл биечлэн хэлнэ (§1). Систем хариуцагч энд FB дугаартайгаар бичиж ангилна (§2–§5).

---

## 1. Ажилтанд: асуудал мэдээлэхдээ юу хэлэх вэ

1. **Хаана:** аль хуудас (жнь Кемп → Ирц, Өрөөний самбар).
2. **Юу хийсэн:** алхам алхмаар (жнь "xlsx файл upload хийгээд Баталгаажуулах дарсан").
3. **Юу болсон:** алдааны мессежийг яг бичигдсэнээр нь, эсвэл **дэлгэцийн зураг**.
4. **Юу болно гэж хүлээсэн.**
5. **Хэзээ:** огноо, цаг.
6. **Ямар төхөөрөмж:** утас эсвэл компьютер.
7. **Ажил зогссон уу:** өөр аргаар хийж чадсан уу.

> 🚨 **Яаралтай (P0) бол шууд залгана:** систем огт нээгдэхгүй; өгөгдөл алга болсон эсвэл буруу хадгалагдсан; өөр хүний мэдээлэл харах ёсгүй хүнд харагдсан.
> Дэлгэцийн зургийг зөвхөн систем хариуцагчид илгээнэ. Хувийн мэдээлэлтэй тул нийтийн чат бүлэгт бүү тавь.

## 2. Ангилал

### Ач холбогдол

| | Утга | Кемпийн жишээ | Хариу |
|---|---|---|---|
| **P0** | Систем ажиллахгүй, өгөгдөл алдагдсан/буруу, аюулгүй байдал | Нэвтэрч чадахгүй байна · импортолсон ирц алга болсон · хоолны тоо системийн алдаанаас болж буруу гарсан · эрхгүй хүн ажилтны мэдээлэл харсан | **Тэр өдөртөө** hotfix (`release/v0.1` → `v0.1.7`+) |
| **P1** | Ажлыг саатуулж байгаа ч тойрох арга бий | 200 ажилтныг гараар оруулахад өдөр зарцуулна (Excel импорт алга) · тайланг Excel-ээр гаргах боломжгүй · ирцийн файлын алдааны мессеж ойлгомжгүй | v0.2-т |
| **P2** | Сайжруулалт, "байвал сайн" | Өрөөний самбарт өнгө нэмэх · утсан дээр товч жижиг байна · шүүлтүүр нэмэх | v0.2 эсвэл дараа |

Эргэлзвэл: **"Ажил зогссон уу?"** Тийм бөгөөд тойрох арга байхгүй бол P0. Тойрох арга байвал P1. Ажил зогсоогүй бол P2.

### Төрөл

| Төрөл | Утга |
|---|---|
| **Алдаа** | Систем буруу ажилласан (алдааны мессеж, буруу тооцоо, хадгалагдаагүй) |
| **UX** | Ажилладаг ч ойлгомжгүй, удаан хийгддэг, олдохгүй байна |
| **Функц** | Байхгүй боломж (шинэ хуудас, импорт/экспорт, тайлан) |
| **Өгөгдөл** | Буруу/дутуу өгөгдөл оруулсан, засах шаардлагатай (системийн алдаа биш) |
| **Гүйцэтгэл** | Удаан ачаалж байна, гацаж байна |
| **Сургалт** | Систем зөв ажилласан, хэрэглэгч хэрхэн ашиглахыг мэдээгүй → зааварт нэмнэ |

### Төлөв

`Шинэ` → `Ангилсан` → дараах дөрвийн нэг:
- `Hotfix` → `Шийдсэн`
- `v0.2` (бүртгэлийн ID-тай)
- `Backlog`
- `Татгалзсан` (шалтгаантай)

Хэрэглэгчийн буруу хэрэглээ (Сургалт) бол `Шийдсэн (тайлбарласан)`.
